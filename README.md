# dotfiles

Configuración personal para entorno Wayland.

## Componentes

| Paquete | Descripción |
|---------|-------------|
| **Sway** | Window manager (Wayland) |
| **Kitty** | Terminal |
| **Waybar** | Barra de estado |
| **Mako** | Notificaciones |
| **Tofi** | Launcher |

## Atajos principales

- `Super + Return` → Terminal
- `Super + m` → Menú (tofi)
- `Super + n` → Thunar
- `Super + b` → Firefox
- `Super + o` → Edge
- `Super + flechas` → Navegar ventanas
- `Super + r` → Modo resize
- `Print` → Captura pantalla
- `Super + Print` → Captura con selección

## Instalación

Gestionado con `manifest.toml`. Los configs se linked a `~/.config/`.
